# Nourish

Mobile-first calorie tracking for everyday Egyptian meals. Next.js 14, Tailwind, shadcn/ui, Framer Motion. Mock data only.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- `/` dashboard with a populated log
- `/onboarding` 5-step intro and calorie reveal
- `/log` local dishes, recents, favorites
- `/profile` goals, units, theme
