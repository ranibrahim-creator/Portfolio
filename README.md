# Nourish

A calorie counting mobile app built with [Expo](https://expo.dev) and React Native. It runs on iOS, Android, and web.

## Features

- Daily calorie ring with remaining vs goal
- Protein, carbs, and fat tracking
- Breakfast, lunch, dinner, and snack logging
- Searchable food database plus custom foods
- Water tracker
- Weekly diary, averages, and streaks
- Mifflin–St Jeor calorie goal calculator
- Local persistence on device

## Run it

```bash
npm install
npx expo start
```

Then press `i` for iOS, `a` for Android, or `w` for web. You can also scan the QR code with the Expo Go app.

npm run typecheck
